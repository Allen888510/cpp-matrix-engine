# C++ Matrix Engine

A C++ matrix computation engine built from scratch for learning high-performance computing and AI acceleration.

## Goals

This project is created to learn:

- Modern C++
- Matrix computation
- High-performance computing
- CPU optimization
- Benchmarking
- AI inference acceleration

## Roadmap

- [ ] Matrix class
- [ ] Matrix addition
- [ ] Matrix multiplication
- [ ] Matrix transpose
- [ ] Unit testing
- [ ] Benchmarking
- [ ] Cache optimization
- [ ] Multithreading
- [ ] SIMD optimization
- [ ] Quantized matrix multiplication
